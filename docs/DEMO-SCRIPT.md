# 60 秒演示：拍摄脚本与清单（三个 agent 接力版）

> 目标：让一个从不认识这个插件的人看完能说出「一句话派给 agent，它自己编译、部署、
> 验证，结果和证据回到我面前」。
>
> 静音可看（全靠字幕），60 秒以内。线上先放的是示意动画 [`demo.html`](./demo.html)；
> 这份文件是**拍真实版**用的 —— 真实版一上线就替换动画，转化率会更高。

---

## 一、镜头表

| 时间 | 画面 | 字幕（同时是旁白） |
|---|---|---|
| 0–6s | 三台设备并排：手机、Windows 编译机、Android（Termux）。三台 Mesh 页里互相可见 | 三台设备各装一次，agent 自己找到彼此。 |
| 6–16s | 手机上的 DSH 会话，输入：`编译 Windows 版，装到 Android 上验证，截图和日志发我`，点发送 | 你在手机上说清楚要什么结果。 |
| 16–28s | Windows 那台：Mesh 页出现任务，会话自己开起来，构建在跑，最后一行是产物路径 | 第一个 agent 接过去编译 —— 你不用管它用什么命令。 |
| 28–36s | Windows 的会话里出现 `→ 交给 Android-04`，切到 Android：安装、启动、截图、抓日志 | 编完，它自己交给下一个 agent 部署验证。 |
| 36–46s | 手机收到通知，点开「任务」→ 结果卡：产物、退出码、安装/启动结果、截图、日志 | 结果合并回你面前，连同证据。 |
| 46–52s | 结果卡停 2 秒，叠一行安装命令 | `dsh plugin add dsh-plugin-mesh` |
| 52–58s | 尾卡：`一句话，三个 agent 接力` + 网址 | — |

**硬规则**

- 只讲一条链路（编译 → 部署 → 验证），不要在片子里演示第二个功能。
- 必须出现三个东西：**编译产物**、**Android 启动证据**、**合并结果**。
- 不解释组播、端口、tailnet —— 一个字都不要。

---

## 二、录制前准备

1. 三台设备都升级到同一版本、重启过 DSH，Mesh 页互相可见。
2. 清空「任务」里的旧记录，避免出现真实项目名 / 客户名 / 路径。
3. Windows 那台提前 `pnpm install` 过，构建在 60 秒内跑完；先跑一遍确认退出码 0。
4. Android 那台（Termux）已装 adb，且能连上目标手机；提前手动装一次、启动一次，
   确认 adb 路径和权限没问题 —— 录到一半卡在 adb 上是最常见的翻车点。
5. 手机打开通知权限；字号调到 14px 以上；深色模式全片统一（可选）。
6. 录屏 1080p / 30fps；不要录到 Dock、菜单栏、通知里的私人信息。

---

## 三、剪辑

- 全片 55–60 秒；构建等待用 4× 快进 + 字幕说明，不要真实等 40 秒。
- 字幕固定在底部，一条不超过 18 个汉字。
- 结尾 3 秒必须留安装命令 + 网址，方便截图传播。
- 导出 MP4（H.264），15 MB 以内；封面用「结果卡」那一帧。
- 不加背景音乐；要加就压到 -28 dB 以下（多数人在静音环境看）。

## 五、验收

找 5 个用 DSH 但没用过这个插件的人，只给他们看这支视频，然后问：

1. 它是干什么的？
2. 你会拿它干什么？
3. 有什么地方没看懂？

三个人能答对前两问，就算过关；否则先改视频，不要改产品。
