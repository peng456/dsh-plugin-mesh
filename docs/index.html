从零开始：装两次，然后一句话

不用懂网络，也不用背命令。整套只有两步：每台设备先装 DSH，再给每台装 mesh。装完什么都不用配 —— 同一局域网里它们几秒内自己碰头。

  1. 给每台设备装上 DSH

    DSH 是 DeepSeek 官方的开源项目，官方下载页：deepseek.com/harness（源码在 GitHub）。

    WindowsSetup.exe，双击装完打开官方 macOSDMG，Apple 芯片 / macOS 13+官方 Linuxdeb / AppImage / tar.gz社区 Androiddsh-Go：免 root、免 Termux社区 Androiddsh-mobile：备选壳，arm64 / x86_64社区 鸿蒙5 及更早：装安卓版 dsh-Go 的 APK社区 鸿蒙5 之后（纯血）：装 dshm 的原生 HAP社区 iOS暂无本地客户端，关注 dsh-Go关注
    Intel Mac社区桌面端 v2.0.13，支持 macOS 12，universal 含 Intel社区
    命令行npx @deepseek-ai/dsh web，任何系统，需先装 Node.js

    标「官方」的是 DeepSeek 直接发布；其余（DSH Desktop、dsh-Go、dsh-mobile、dshm）是社区项目。

    鸿蒙：5 及更早装安卓版（dsh-Go 的 APK）；5 之后是纯血鸿蒙，装 dshm 的 HAP。不想装东西的话，也可以直接用浏览器打开电脑上的 DSH（设置 → 桌面设置 → 局域网访问）。

  2. 再给每台装 mesh（三种方式，任选一种）

    ① 点界面：插件市场

    侧栏打开「插件市场」，搜索框输入 dsh-plugin-mesh，点安装，装完重启 DSH。

    侧栏没有这个入口：进 设置 → 插件市场，选一个市场启用（桌面端内置 dsh-community-market），再回侧栏。搜不到就用下面两种。

    ② 一行命令 
    dsh plugin add dsh-plugin-mesh

    在 DSH 自带的终端里跑（桌面端能开一个，Profile 已经配好；这条命令改的就是 desktop profile）。自己用 dsh web 起的，换成 dsh plugin --profile web add dsh-plugin-mesh。

    ③ 直接跟对话框说

    新开一个会话，发这一句就够了：

    「帮我把 dsh-plugin-mesh 装上，装完提醒我重启。」

    它会在自己所在的环境里动手装。如果它说装不了，多半是那台桌面端管着自己的插件：按它指的路径点一次「插件市场」即可，别自己硬试。

  3. 重启 DSH，给这台机器起个名字

    插件在启动时加载，装完必须重启一次。重启后侧栏会出现「Mesh」，点开先给这台机器起名（默认主机名），别的机器就靠这个名字找你。

  4. 派一个活，然后回来看结果

    两台在同一局域网，几秒内就会互相出现。选一台设备 →「派发任务」，或者直接在会话里以 @机器名 开头说话。派出去只是「送达」；对端跑完会把结果派回来，出现在「任务」里。

只装一台也能先看：Mesh 面板里有个 60 秒演示，不连接别的机器，也不花 token。

From zero: install twice, then one sentence

No networking, no commands to memorise. Two steps: put DSH on every device, then put mesh on every device. Nothing to configure — on the same LAN they find each other within seconds.

  1. Put DSH on every device

    DSH is DeepSeek's official open-source project. Official downloads: deepseek.com/harness (source on GitHub).

    WindowsSetup.exe — run it, open the appOfficial macOSDMG, Apple silicon / macOS 13+Official Linuxdeb / AppImage / tar.gzCommunity Androiddsh-Go: no root, no TermuxCommunity Androiddsh-mobile: alternative shell, arm64 / x86_64Community HarmonyOS5 and earlier: install the Android dsh-Go APKCommunity HarmonyOSafter 5 (pure): install dshm's native HAPCommunity iOSNo on-device client yet — follow dsh-GoWatch
    Intel MacCommunity desktop v2.0.13 — supports macOS 12, universal (Intel included)Community
    Terminalnpx @deepseek-ai/dsh web — any OS, needs Node.js installed

    Rows marked “Official” are published by DeepSeek; everything else (DSH Desktop, dsh-Go, dsh-mobile, dshm) is a community project.

    HarmonyOS: 5 and earlier install the Android build (dsh-Go's APK); after 5 it is pure HarmonyOS, so install dshm's HAP. Rather not install anything? Open the DSH running on your computer in a browser (Settings → Desktop settings → LAN access).

  2. Then put mesh on each machine — any one of three ways

    ① Click: the plugin market

    Open “Plugin market” in the sidebar, type dsh-plugin-mesh in the search box, install, then restart DSH.

    No such entry in your sidebar: go to Settings → Plugin market, enable one source (the desktop app bundles dsh-community-market), then come back. Nothing found: use one of the two ways below.

    ② One command 
    dsh plugin add dsh-plugin-mesh

    Run it in DSH's own terminal (the desktop app can open one with the profile already set; this command edits the desktop profile). Started with dsh web yourself? Use dsh plugin --profile web add dsh-plugin-mesh.

    ③ Just say it in the chat box

    Start a new session and send this one sentence:

    “Install dsh-plugin-mesh for me and remind me to restart.”

    It installs in whatever environment it is running in. If it says it cannot, that desktop app manages its own plugins: click “Plugin market” once where it points you instead of forcing it.

  3. Restart DSH, then name this machine

    Plugins load at startup, so restart once. “Mesh” then appears in the sidebar: open it and give this machine a name (hostname by default). Peers find you by that name.

  4. Dispatch one task, then come back for the result

    On the same LAN they show up within seconds. Pick a device → “Dispatch”, or start a chat message with @machine. Sending only means “delivered”; the peer dispatches the result back into “Tasks” when it is done.

One machine is enough to look around: the Mesh panel has a 60-second demo that connects to nothing and spends no tokens.

它是怎么做到的 不关心可以跳过

  • 自己找 —— 每 5 秒向局域网发一个心跳包，同时监听同一个地址。所以不用填 IP。
  • 派活 —— 把任务发给对方，对方自动开一个 agent 会话去做，做完再派回来。
  • 两条路 —— 局域网优先；不在同一网络时，走插件自带的用户态 Tailscale（自动下载，不用装客户端）。需要免费注册 Tailscale 并生成一个授权码。
  • 会什么 —— 每台机器把自己装的运行时、内存、显卡报上来，派活之前就能看出它做不做得了。

How it works skip if you only want the outcome

  • Discovery — every 5 seconds each machine sends a heartbeat to the LAN and listens on the same address. That is why you never type an IP.
  • Dispatch — a task is sent to the peer, which opens an agent session automatically, does the work, and dispatches the result back.
  • Two channels — LAN first; across networks it falls back to a bundled userspace Tailscale node, downloaded automatically. No client to install. Needs a free Tailscale account and an auth key.
  • Capabilities — each machine reports its runtimes, memory and GPU, so you can tell before dispatching whether it can do the job.

常见问题

  • 看不到对方 —— 依次确认：① 两台在同一局域网？ ② 对端也装了、也重启了？ ③ 防火墙放行了 TCP 45917 和 UDP 45892？ 还不出现就点「局域网探测」—— 只要端口通，扫描就能发现，不依赖组播。
  • 结果在哪 —— 在「任务」里。派发的返回只代表对端收下了，不代表跑完了；跑完的结果由对端派回来。
  • 安全保护 —— 默认装好就能直接派活，没有确认弹窗。要加保护：在「连接 → 配对码」里开配对，两端用同一个码，码不一致的派活请求会被直接拒（HTTP 403）；临时不想被任何人找到，用面板上的「一键关闭」。所有数据都在本机，没有账号、没有云端。
  • Android 老掉线 —— 是系统省电在杀后台，不是插件的问题。把 DSH 加进电池优化白名单。

Troubleshooting

  • No peers — check in order: same LAN? peer also installed and restarted? firewall allows TCP 45917 and UDP 45892? Still nothing: use “Scan subnet” — if the port is reachable, the scan finds it without multicast.
  • Where is the result? — In “Tasks”. A successful dispatch only means delivered; the peer dispatches the result back when it finishes.
  • Protection — dispatch works out of the box, with no confirmation prompt. To guard it: turn on “Pairing code” under Connect, so both ends share one code — a dispatch carrying a different code is rejected with HTTP 403. To stop being discoverable at all, use “One-click off” in the panel. All data stays local: no account, no cloud.
  • Android keeps dropping — the OS is killing background apps, not a plugin bug. Add DSH to the battery whitelist.
