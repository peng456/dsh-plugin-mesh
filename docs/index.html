DSH Mesh

把几台电脑连起来，互相派活。

每台都装上，它们自己就找到了彼此 —— 不用配对码、不用填 IP、不用装 Tailscale。

Connect your DSH machines. Let them hand work to each other.

Install on each one and they find each other — no pairing codes, no IP addresses, no Tailscale client.

快速开始

  1. 每台机器装一遍

    dsh plugin add dsh-plugin-mesh

    desktop profile 要在 DSH 自带终端里跑；其它 profile 用普通终端即可。

  2. 重启 DSH

    插件在启动时加载，装完必须重启一次。

  3. 侧栏点「Mesh」

    看到别的机器就是成功了。看不到就看下面的排查。

Quick start

  1. Install on every machine

    dsh plugin add dsh-plugin-mesh

    The desktop profile needs DSH's own terminal; other profiles work from a normal one.

  2. Restart DSH

    Plugins load at startup, so restart once.

  3. Click “Mesh” in the sidebar

    Seeing another machine means it worked. If not, check troubleshooting.

设计原理

  • 自己找 —— 每 5 秒向局域网发一个心跳包，同时监听同一个地址。所以不用填 IP。
  • 派活 —— 把任务发给对方，对方自动开一个 agent 会话去做，做完再派回来。
  • 两条路 —— 局域网优先；不在同一网络时，走插件自带的用户态 Tailscale（自动下载，不用装客户端）。
  • 会什么 —— 每台机器把自己装的运行时、内存、显卡报上来，派活之前就能看出它做不做得了。

How it works

  • Discovery — every 5 seconds each machine sends a heartbeat to the LAN and listens on the same address. That is why you never type an IP.
  • Dispatch — a task is sent to the peer, which opens an agent session automatically, does the work, and dispatches the result back.
  • Two channels — LAN first; across networks it falls back to a bundled userspace Tailscale node, downloaded automatically. No client to install.
  • Capabilities — each machine reports its runtimes, memory and GPU, so you can tell before dispatching whether it can do the job.

排查障碍

  • 看不到对方 —— 依次确认：① 两台在同一局域网？ ② 对端也装了、也重启了？ ③ 防火墙放行了 TCP 45917 和 UDP 45892？
  • 组播被挡 —— 很多路由器会挡。点面板上的「扫描本网段」主动扫一次即可。
  • Android 老掉线 —— 是系统省电在杀后台，不是插件的问题。把 DSH 加进电池优化白名单。
  • 安全 —— 默认不校验密钥：同一网络里能连上 45917 的人都能给你派活。在咖啡厅、宿舍这类网络，建议打开 requirePairing。

Troubleshooting

  • No peers — check in order: same LAN? peer also installed and restarted? firewall allows TCP 45917 and UDP 45892?
  • Multicast blocked — common on many routers. Use the panel's “Scan subnet” button instead.
  • Android keeps dropping — the OS is killing background apps, not a plugin bug. Add DSH to the battery whitelist.
  • Security — by default the key is not checked: anyone on the same network who can reach 45917 can send you work. On café or dorm networks, consider enabling requirePairing.
