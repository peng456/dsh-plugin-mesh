## 现状（v0）

| 项 | 状态 |
|---|---|
| 协议实现 | **2 份**：`lib/`（DSH 插件）与 `mcp-mesh/mesh-node.mjs`（自建组播 + `/mesh/v1` 兼容 + 自报 `app:"dsh-mesh"`） |
| 名片区 | v2；缺 `hostKind` / `wakeLevel` / `transports` / `mcp` |
| 一致性测试 | 无；但有 28 个 `_selftest-*.mjs` 可演化 |
| web 三壳 | 三种壳各自实现探测（`dsh-mesh-web/`），`node_modules` 是外部部署的 symlink |

**为什么这是最贵的一条**：现在是两份，第三个接入方一到就是三份。**每接一个宿主，分叉多一处。**

## C-v1 · 收编（一份实现）

| 工作项 | 做到什么 | 验收 |
|---|---|---|
| `mesh-core` | 从 `lib/` 抽出内核：identity · discovery · scan · gates · journal · events · router | 一份实现，两种承载（内嵌 / 守护） |
| `mcp-mesh` 收编 | 删掉自建组播与 peer 表，只留 MCP 门面转发 | 面板不再分不清「一个壳」和「一台真的 DSH」 |
| 名片区 v3 | `hostKind` / `wakeLevel` / `transports` / `mcp` | 新老混跑：**缺字段按 v2 降级，未知字段忽略** |
| `dsh-mesh-web`（dshInWeb）收编 | 三种壳挂到 core 之上；解掉 `node_modules` 外部 symlink | extension 路径端到端可用（已实测） |

**顺带一个便宜的发现**：纯页面方案被 CORS + ORB 挡死，且「端口关闭 / 主机不存在 / 不发 CORS」
三者**不可区分**（实测 253 无应答）。**给节点加一个显式 CORS 头可能是一天的事，比死磕 IWA 划算。**
浏览器当看板 / 遥控器，当不了 mesh 节点 → web 产出归 [`U`](./ui.md)。

## C-v2 · 一致性测试

| 组 | 覆盖 |
|---|---|
| 名片 | v3 字段、v2 降级、未知字段忽略 |
| 信封 | 必备字段、`summary` 兼容、错误形态 |
| 事件 | 8 类事件、`since` 游标、断线重连不重复 |
| 取消 | 「已停」/「太晚」两种回执 |

**做法**：把 28 个自测里与线协议无关的留下，抽出一层 `conformance/` 只测**线上一刻**的行为。

**验收**：一份实现跑得过即兼容；测试不依赖本仓任何内部模块。

## C-v3 · 冻结（条件触发，不设日期）

**四项全满足才发**

| # | 条件 | 怎么验 |
|---|---|---|
| C1 | 交账率 ≥95%、取消确认 100% | 连续 4 周账本（[`route.md`](./route.md) R-v1） |
| C2 | 高危确认上线且未误拦 | ≥3 台设备跑满 2 周 |
| C3 | 连续 8 周无 P0 事故 | 事故记录为空 |
| C4 | **第三方实现 ≥1 或 conformance 被非本仓代码跑过** | 仓库外证据 |

**C4 是硬门槛**：没有第二个独立实现时，「标准化」是自嗨。

**工作项**：`v2` 定型 + 版本协商 + 弃用策略；`PLUGIN-SPEC.md` 升级为对外规范；
**稳定面 vs 实验面**（哪些 API 承诺不破）；A2A 适配器挂在这里。

## 闸门

| 关系 | 说明 |
|---|---|
| **出** | C-v1 闸住 [`A`](./adapter.md) 的 v2+（每多接一个宿主，两份实现就多一处分叉） |
| **入** | C-v3 需要 C-v2 + [R-v1](./route.md) 的四周数据 |

## 边界

- 不做公网协议全集（只做「够映射」）
- 不做中心目录 / 注册服务端
- 不做工具协议（MCP 已定局，不做「工具总线」）
- 不静默改形状：任何字段变动先过 conformance
